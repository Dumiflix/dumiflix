Settings

Seedr account

Your Seedr credentials are stored locally on the TV and sent directly to Seedr for sign-in.

TMDB (trending rows)

Powers the "Trending Movies (7d)" + "Trending TV (7d)" rows on Home. Paste your TMDB v4 API Read Access Token (the long "eyJhb…" one). Free from themoviedb.org → Settings → API.

Google Drive

Your library uses an opaque ._cache_<hex> folder in Drive, generated per install and reused across launches. After reinstalling, use Reattach existing folder to select a previous library. Sign in with your Google Cloud OAuth client (type "TVs and Limited Input devices").

Phone file server

Requires a separate companion file server, not included in this repository. It powers the Files tab and browses storage attached to your phone. Enter its host and port; default port 5052.

Media relay (qBittorrent)

Requires a separate companion relay service for qBittorrent, not included in this repository. Enter the service's host and port; default port 5052.

Auto-detect scans the local network for the relay service. The TV also re-discovers it when the saved host stops answering, such as after a DHCP address change.

Laptop player (HDMI)

Uses the optional Windows mpv adapter included in the laptop engine. Configure the engine and an external display or compatible HDMI audio receiver to play cached titles. Any failure falls back to normal TV playback automatically.

Bluetooth audio

Requires a separate companion Bluetooth control service, not included in this repository. Connect headphones or speakers already paired in the TV's Bluetooth settings.

Engine

Laptop host & token

Idle screensaver

When the app sits idle on a browse screen, fade in a cozy ambient loop until you press any button on the remote. Plays videos from the configured file server's Ambient folder, falling back to public Mixkit clips when no local videos are available; never runs while you're watching something. The scene chips below only pick the Mixkit fallback set.

Subtitles

When a torrent doesn't include subtitles, fetch a matching one from OpenSubtitles. Register a free consumer at opensubtitles.com/en/consumers and paste the API key below.

YouTube Music (spike)

Paste cookies from a signed-in browser session on music.youtube.com (DevTools → Application → Cookies). They live only on this TV.
